Jutge Web

Jutge.org, en el navegador.Una extensión para vscode.dev y github.dev

La extensión oficial de Jutge solo funciona en VS Code de escritorio. Esta versión no oficial hace que todo funcione en VS Code para la Web: iniciar sesión, leer enunciados, probar juegos de prueba y enviar soluciones, desde cualquier navegador: tablets, Chromebooks u ordenadores compartidos.

Por qué la extensión oficial no funciona en la web

En vscode.dev, las extensiones no se ejecutan en tu ordenador: se ejecutan dentro del navegador, en un entorno aislado. La extensión oficial necesita cuatro cosas que ahí no existen. Cambia de entorno para verlo.

  • Leer y escribir tus archivos

    Usa fs, el sistema de archivos de Node.js, para tu código y los juegos de prueba.No hay Node.js: fs no existe, y tus archivos pueden estar en un repo de GitHub, no en un disco.

  • Ejecutar compiladores

    Lanza g++, python o ghc instalados en tu máquina con child_process.Un navegador no puede lanzar programas instalados en el sistema.

  • Piezas internas de Node.js

    Usa os, path y Buffer para rutas, carpetas temporales y datos binarios.Tampoco existen en el navegador: el código ni siquiera llega a cargarse.

  • Otras dos extensiones

    Depende de la extensión de Python de Microsoft y de un visor de PDF.Ninguna de las dos funciona en la web, así que VS Code bloquea la instalación.

En escritorio, todo en orden.En el navegador, el Marketplace la marca como no disponible y no se puede instalar.

Qué he cambiado

La lógica de la extensión (cursos, enunciados, envíos, veredictos) es la misma. Lo que depende del entorno queda detrás de una capa de plataforma con dos implementaciones, y VS Code carga la que corresponde.

Código compartido

Vistas, cliente de la API de Jutge, juegos de prueba y envíos. Los archivos se leen y escriben con vscode.workspace.fs, que funciona igual con una carpeta local o con un repo de GitHub.

Capa de plataforma

Un único punto que decide cómo se ejecuta el código y dónde se guardan las cosas.

EscritorioNode.js

  • Igual que la extensión oficial
  • Compiladores locales: g++, Python, GHC

Navegadornuevo

  • Python con Pyodide (WebAssembly) en un Web Worker
  • C++ y Haskell con la API de Compiler Explorer
  • Errores en el panel de salida y subrayados en el código

El Jutge de la UPC estaba a medias: solo llegaba al escritorio. Decidí terminarlo.

Jutge.org es el juez en línea con el que se aprende a programar en la UPC, y su extensión oficial para VS Code es muy buena. Pero se queda en el escritorio, justo donde un editor en el navegador sería más útil: en tablets, en Chromebooks o en ordenadores donde no se puede instalar nada.

Para que cualquiera pueda usar Jutge desde un navegador, adapté la extensión a vscode.dev: separé lo que depende del sistema, llevé Python al navegador con WebAssembly y conecté C++ y Haskell con Compiler Explorer. La desarrollé con la ayuda de Claude Code y está publicada en el Marketplace.

El código es abierto, con la misma licencia que el original (Apache 2.0). Si a los autores de Jutge les sirve, encantado de que lo integren en la extensión oficial.
